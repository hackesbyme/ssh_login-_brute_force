# 🔐 SSH Brute-Force Login Script (Pwntools)

This Python script attempts to brute-force an SSH login using a password wordlist. It's built with the **Pwntools** library and is ideal for use in **penetration testing labs** or **CTF challenges**.

---

## 🚀 Features

- Interactive prompts for IP, username, and wordlist
- Wordlist file validation
- Clear attempt tracking
- Lightweight and fast using Pwntools
